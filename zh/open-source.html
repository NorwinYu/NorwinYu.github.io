02 / 方法

我贡献什么。

不是为了刷 commit 数加功能。有用的贡献往往就是那个测量，或者那句少了就让下一个人没法做决定的话。

01

去测那些别扭的机器

老卡、慢 CPU、长上下文。社区需要人们手上真有的硬件跑出来的数字，而不只是干净的 benchmark 机器。

02

把原始数据交回去

报告里有请求、配置、并发数据和脱敏后的设置，别人可以重跑，也可以质疑这个结果。

03

补上接口的缺口

客户端查不到模型的上下文时，最小的有用补丁是那个 API 字段，不是更长的 README。
