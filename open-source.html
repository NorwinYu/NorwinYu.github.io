02 / Method

What I contribute.

Not features for the sake of a commit count. The useful contribution is usually the measurement or the missing sentence that lets the next person make a decision.

01

Measure the awkward rig

Old cards, slow CPUs, long context. The community needs numbers from the hardware people actually own, not only clean benchmark boxes.

02

Return the raw data

Reports include requests, configs, concurrency data and sanitized settings so someone else can rerun or challenge the result.

03

Fix the interface gap

When a client cannot discover a model's context, the smallest useful patch is the API field, not a longer README.
