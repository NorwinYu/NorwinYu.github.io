02 / Principles

Method.

Four defaults that show up in the code, the writing and the way a project gets scoped.

01

Local before cloud

Private data stays on the desk. Use frontier models where the capability gap is real, not by default.

02

Ship the loop

A playable slice with an end state beats a polished scene with no game. The fifth run is the test.

03

Measure, then trust

Prompt-level splits, seed checks and screenshots. A single run is an anecdote, not a result.

04

Write it down

Method, caveat, failure. The notes are how the next project starts faster.
