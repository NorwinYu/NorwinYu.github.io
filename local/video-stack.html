Local / video stack

20B on 2 × 22 GB.

MiniMax H3 is a 20.11B video-and-audio transformer. It does not fit on one card, so tensor parallelism is not an accelerator here — it is the difference between a usable run and a fan that runs for four minutes.

03 / Three versions

1.31×, then 2.25×, then 2.97×.

The sharding was correct in the first version. What was missing was a thread, not a split.

Tensor-parallel versions and speedups
Versions/step (864×480)SpeedupWhat changed
Single card44.61.00×Chunked on one card
TP2 v134.01.31×Column/row split with a single launch thread
TP2 + one thread per rank19.82.25×Each rank launches its own kernels

CauseThe W4A8 GEMM blocks its calling host thread, so one launch thread serialised the two cards: measured overlap 5%. One thread per rank lifted it to 91%, with bit-identical output (frame MAE 0.0000).

04 / Probes

The three-row diagnosis.

Two GPUs, one GEMM, three launch strategies. Overlap is the number that separates "sharded" from "parallel".

05 / Reproduce

Starting the two-card server.

The device order matters: exposing only one card silently collapses every cuda:0 in the graph onto it.

export CUDA_VISIBLE_DEVICES=1,0          # GPU1 first, so cuda:0 is the compute card
python main.py --listen 127.0.0.1 --port <port> --reserve-vram 1.5 --vram-headroom 0.5     --disable-pinned-memory --fast-disk

python scripts/bench.py examples/smoke_t2v.json smoke   # self-contained sample

06 / Caveats

What the speedup is not.

The 2.97× comes from real renders on the workstation, and it is specific to a quantisation, a model and a pair of cards.

01

Not a general TP result

These numbers come from W4A8 on two modified 22 GB Turing cards at a 250 W limit. Different cards, quantisation or model shape will produce different overlaps.

02

NUMA is part of it

The cards sit on different NUMA nodes. The 13 ms all-reduce partially pays for that topology; another board would change it.

03

Weights are not here

The code is MIT, the model weights are not in the repository and follow MiniMax's own licence. The sample is a self-contained text-to-video case.
